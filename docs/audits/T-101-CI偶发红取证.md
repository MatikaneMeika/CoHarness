## 关键发现

1. **窗口内没有「无因偶发红」**：22 轮 failure 全部落到具名提交与对应修复，没有一轮需要「再观察」。
2. **`test_apply_check_passes_a_doc_only_patch` 是级联指示器，不是那条偶发红**：它出现在窗口内**全部 15 轮**测试级红里。它在临时副本里跑一套完整自测，内层任何一条红都会把它带红——`36684881773` 就是内层撞上 git 后台维护竞态。把它当成「那条偶发红」会误诊到错误的方向。
3. **7 轮红来自 CI 自己的失败诊断链**，不是被测代码；这类红会让真实信号消失（`36509937818` 是极端例子：测试全绿却整轮判红）。该链条修完（2026-09-29 03:52）之后，窗口内未再出现。
4. **红腿分布**：Windows 腿参与 13/15 轮测试级红，是主战场；macOS 腿只单独红过一次（`36682250136`，唯一失败腿）。
