# 流程：bugfix（缺陷修复）

## 步骤

### 1. 复现与归因
- 最小复现步骤/脚本；复现不了就向用户要信息，禁止盲修
- 根因一句话 + 影响面（还有哪些调用方/组件受影响）

### 2. 建修复卡 【门禁：方案确认后动手】
- 单卡：根因、修法、回归要求；跨组件 bug 拆多卡并标同源
- 紧急热修可先修后补卡，但**当日必须补卡并走 review**，不得留"无卡改动"过夜

### 3. 最小修复
- 只改根因相关最小范围；顺手重构禁止
- 回归测试与修复同卡交付

### 4. 回归
- 原复现用例 + 全量 `{{TEST_CMD}}` + 主链路冒烟（跨组件 bug 必冒烟）

### 5. 收尾
- reviewer 过卡 → integrator 合并收尾
- CHANGELOG：[修复] + 根因一句话
- 根因暴露共性漏洞（如所有组件同缺输入校验）→ 开独立卡处理，不在修复卡里夹带
