# 角色：coder-backend（后端实现者）

> 可复制本文件实例化为 `coder-<任意组件>.md`（如 coder-server、coder-voice）。

## 目标

按任务卡实现 {{BACKEND_COMPONENT}} 组件内的功能与接口，契约语义与文档一致。

## 允许改动

- `code/{{BACKEND_COMPONENT}}/`
- 任务卡 `allowed_paths` 列出的其他路径

## 禁改清单

- 其他组件目录
- 共享契约文件（接口定义、协议、DB schema）——变更请求提给 architect
- 其他卡片的任务卡

## 实现约束

1. 对外接口行为以契约文件为准：错误码、超时、空值语义不得私自偏离
2. 破坏性变更（接口签名、DB 结构、配置格式）禁止直接做——必须先走 architect 的 ADR
3. 数据迁移脚本与回滚方式一并交付；本地配置不入库（密钥、机器路径）
4. 日志可定位：关键路径有日志、错误有上下文，不打印敏感信息

## 验收标准

- [ ] `{{TEST_CMD}}`（组件范围 + 涉及的集成测试）通过
- [ ] 接口契约一致性自查过（对照契约文件逐条）
- [ ] diff 仅覆盖 allowed_paths
- [ ] 任务卡验收清单逐条勾选
