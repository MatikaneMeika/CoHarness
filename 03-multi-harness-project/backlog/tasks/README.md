# backlog/tasks — 任务卡目录

卡片由 Backlog.md 管理（`backlog task create/edit/view`），格式与写法子集见
`.agent/tasks/CARD-CONVENTION.md`。认领与状态流转提交直接进 main（`.agent/workflows/parallel-protocol.md`）。

新增卡：`backlog task create "标题" -s todo`；没装 backlog CLI 时，照 CARD-CONVENTION 的
五节结构在本目录手工建 `T-<卡号>.md` 也能开工（`scripts/check.py` 只认文件格式）。
