# 流程：doc-from-scratch（从零写一份文档）

## 步骤总览

```
需求登记 → 大纲[门禁1] → 分章写作 → 合并统一 → 导出 → 核验[门禁2] → 交付
```

## 步骤明细

### 1. 需求登记
- 用户需求 + 全部参考资料入库（资料清单记入大纲的素材需求节）
- 建立 `docs/口径与术语.md`：术语、人称时态、字数口径、格式要求一次写全

### 2. 大纲（outline-writer）【门禁 1：用户确认】
- 章节树 + 字数分配 + 素材清单；缺的资料此环节就向用户要

### 3. 分章写作（content-writer）
- 一写手一文件并行；每章交章末自检块；⚠ 项即时报用户，不留到结尾

### 4. 合并统一
- 术语、衔接、人称过一遍；补"待衔接"处；更新目录/图表编号
- 合并轮不改内容语义，只做一致性

### 5. 导出
- source/ → `export/{{DOC_NAME}}.docx/pdf`，文件名固定
- 导出后 git commit 一次（源 + 产物同 commit）

### 6. 核验（checker）【门禁 2】
- 按 `delivery-checklist.md` 全项核验，❌ 退回对应角色

### 7. 交付
- `docs/CHANGELOG.md` 记一条；向用户报告交付物路径与核验结论
