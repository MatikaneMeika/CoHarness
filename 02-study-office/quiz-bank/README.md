# quiz-bank/ — 题库

按科目一个文件：`<科目>.md`（如 `algorithms.md`、`english.md`，文件名自定）+ `mock-<日期>.md`（模考试卷）。

## 题目格式

```markdown
## Q-001 [S1-3:章节标签] [基础] [2026-09-25]
（题干）

A.  B.  C.  D.

> 考察点：……；教材定位：<教材名> P__
> 答案与要点：……（作答前勿看）
> 关联错题：E-001（如有）
```

## 纪律

- 编号全库唯一（Q-xxx / M-xxx 模考卷）
- 出过的题不重复出，重考用变形题
- 答案与题干同文件但用引用块隔离，quizmaster 出题环节不得展示
