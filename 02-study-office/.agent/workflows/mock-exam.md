# 流程：mock-exam（模拟考试）

适用：阶段检验（每完成一个大模块）与考前冲刺。

## 步骤

### 1. 组卷
- 按真实考试结构：题型、题量、分值、时长全部照搬 {{EXAM_NAME}} 真实规则
- 抽题来源：quiz-bank 为主 + 按考试大纲补新题；已结业考点可少量抽入
- 试卷存 `quiz-bank/mock-<日期>.md`，答案单独一节（作答期间不看）

### 2. 限时作答
- 计时 {{EXAM_DATE}} 考试的真实时长；期间 AI 只计时，不答任何题目问题
- 到点停笔，未答按空处理——模拟的意义在真实压力

### 3. 批改与归因
- quizmaster 批改出分（按真实评分标准：步骤分、选错不得分等）
- error-auditor 逐题归因并入库；**整体错因分布**单独统计（概念/计算/审题/遗忘占比）
- 时间维度一并分析：哪些题超时、是否时间分配失衡

### 4. 复盘
- 输出模考报告：总分 / 各科得分率 / 错因分布 / 时间分配问题 / 与上次模考对比
- 得分率低的章节进 topic-drill 队列；syllabus.md 掌握度整体校准
- 考前最后一周：mock 频率提高，错题只复习"已结业但仍错"的高危题
