# 流程：debug（代码跑不通的修复）

适用：复现实验失败、报错、结果明显不对。

## 步骤

### 1. 固定现场
- 完整报错信息 + 复现命令 + 环境（语言版本、依赖版本、OS）一次收集齐
- 禁止"改一下试试"式盲改——先让错误稳定重现

### 2. 三层定位（按序排查，命中即停）
1. **环境层**：依赖缺失/版本不符、路径不对、编码问题（Windows GBK vs UTF-8 是重灾区）
2. **输入层**：数据文件格式、参数取值、边界输入
3. **代码层**：读报错堆栈定位到行，加最小打印或断点确认中间状态

### 3. 修复
- 最小改动修复当前错误
- **红线**：不许注释掉报错代码、删断言、捕获异常后静默继续——这些是掩盖，不是修复
- 同类错误一次修完（比如三处都有同一编码问题）

### 4. 重跑验证
- 原失败命令重跑通过 + 周边功能未被误伤（跑全量已有测试/脚本）

### 5. 记录（可选但推荐）
- 排查超过 3 轮的坑，在 `docs/notes.md` 记一条：现象 → 根因 → 修法
- 这些笔记期末复习和下次作业都值钱
