# 流程：daily-session（每日学习会话）

## 步骤

### 1. 状态读取（每次会话必做）
- 读 `syllabus.md`（章节掌握度、计划进度）
- 读 `error-log.md`（今日到期错题清单）
- 对照备考卡：距离 `{{DUE_DATE}}`（截止/考试日期）还有多少天、进度是否落后

### 2. 今日计划建议【门禁：用户确认】
- 格式：到期错题重测 N 题 → 薄弱考点讲解 M 个 → 新章节推进 X 小节（时间盒按 {{DAILY_HOURS}} 切）
- 进度落后时明确说出来，建议取舍（砍新内容保复习）

### 3. 执行
- 到期错题：error-auditor 重测并更新轮次
- 新内容：quizmaster 出题 → 用户作答 → 批改 → 错题进 error-auditor
- 卡壳的考点：切 tutor 追问式讲解

### 4. 收尾更新（必做，不等用户提醒）
- `syllabus.md`：今日章节掌握度、最近复习日更新
- `error-log.md`：新增错题、到期错题结果
- 今日小结 ≤5 行：学了什么 / 正确率 / 明日建议
