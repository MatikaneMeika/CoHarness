# 流程：new-feature（新功能）

## 步骤总览

```
理解需求 → 建任务卡[门禁1] → 实现(coder) → 自审(reviewer) → 测试运行[门禁2] → 收尾
```

## 步骤明细

### 1. 理解需求
- 用 ≤5 行复述需求：做什么、给谁用、怎么算完成
- 有歧义**先问**，禁止按猜测开工

### 2. 建任务卡 【门禁 1：用户确认后才能动代码】
- 从 `.agent/tasks/TEMPLATE.md` 复制为 `T-<三位序号>-<短横线摘要>.md`
- 填写：title、allowed_paths（精确到目录）、acceptance（可验证的条目，禁止写"做好"这种不可验证项）

### 3. 实现（按 `.agent/roles/coder.md`）
- 先写/改测试再写实现（行为先行），或实现后立即补测试，二选一保持一致
- 中途发现需求本身有问题 → 停下，回到门禁 1

### 4. 自审（按 `.agent/roles/reviewer.md` 清单）
- 结论写入任务卡；fail 项退回步骤 3

### 5. 测试运行 【门禁 2】
- `{{TEST_CMD}}` 全绿 + 手动跑一次主链路（`{{RUN_CMD}}`）确认端到端可用

### 6. 收尾
- 任务卡 status → `done`
- `docs/CHANGELOG.md` 追加条目
- 向用户报告：改了什么、怎么验证的、遗留了什么
